# Weather Diary — Дневник погоды

**Автор:** Якшибаева Арина

## Описание

Простое приложение на Python с графическим интерфейсом (Tkinter) для ведения дневника погоды.  
Позволяет добавлять записи (дата, температура, описание, осадки), фильтровать их по дате и температуре, а также сохранять и загружать данные в формате JSON.

## Запуск

1. Убедитесь, что установлен Python 3.6+.
2. Скачайте файл `weather_diary.py`.
3. Запустите командой:

```bash
python weather_diary.py
