## Описание программы

Movie Library — это графическое приложение для ведения личной коллекции фильмов. Позволяет добавлять фильмы с указанием названия, жанра, года выпуска и рейтинга, фильтровать их по жанру и году, а также удалять записи. Все данные автоматически сохраняются в JSON-файл.

---

## Требования для запуска

- Python 3.6 или выше
- Стандартные библиотеки Python (tkinter, json, os) - дополнительной установки не требуют

---


Как пользоваться
Добавление фильма:

Заполните все поля (Название, Жанр, Год, Рейтинг)

Рейтинг должен быть числом от 0 до 10

Нажмите кнопку "Добавить фильм"

Удаление фильма:

Выберите фильм в списке

Нажмите кнопку "Удалить фильм"

Фильтрация:

По жанру: введите текст в поле "Фильтр по жанру"

По году: выберите условие (>2000, <2000, 2000-2020)

Сброс фильтров:

Нажмите кнопку "Сбросить фильтры"
